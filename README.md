# California Housing Price Prediction

## 📌 Project Overview
This project predicts house prices using machine learning.

## 🧠 Algorithm Used
- XGBoost Regressor

## 📊 Dataset
California Housing Dataset from sklearn

## 📈 Model Performance
- Train R2 Score: 0.94
- Test R2 Score: 0.83
- MAE: 0.31

## ⚙️ Tools Used
- Python
- Pandas
- NumPy
- Scikit-learn
- XGBoost
- Matplotlib
- Seaborn

## 🚀 Goal
To predict house prices using ML and improve model accuracy using feature engineering.
